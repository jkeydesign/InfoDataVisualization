🌐 나만의 사이트를 외부 무료 웹 링크로 배포하는 방법

이 포털 폴더를 인터넷상의 진짜 웹 사이트로 바꾸는 2가지 무료 방법

방법 1. GitHub Pages (추천) 평생 무료 주소
  1. GitHub.com 회원가입 후 로그인합니다.
  2. 우측 상단 [+] ➔ New repository 클릭 후 이름(예: my-dataviz) 입력 후 생성합니다.
  3. 생성된 저장소에 index.html 과 viz_convenience_store.html 을 업로드합니다.
  4. 저장소 [Settings] ➔ [Pages] 탭에서 Branch를 main으로 저장합니다.
  5. 🎉 성공! 1분 후 https://내아이디.github.io/my-dataviz/ 주소로 어디서나 접속 가능합니다!
방법 2. Netlify Drop (10초 완충) 가장 간단함
  1. app.netlify.com/drop 웹사이트에 접속합니다.
  2. 현재 이 작업 폴더(brain/3934b9b4...) 전체를 박스로 드래그 앤 드롭합니다.
  3. 10초 만에 외부 전용 라이브 공유 링크가 바로 생성됩니다!
  4. 생성된 링크 주소를 친구나 발표 자료에 그대로 공유하시면 접속 가능합니다.
